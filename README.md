
# CS 499 — Grazioso Salvare Database Enhancement

### Southern New Hampshire University
**Computer Science Capstone | Database Enhancement**

## Project Overview

This repository contains my enhanced Grazioso Salvare Animal Shelter Dashboard, originally developed for CS 340 Client/Server Development and improved for my CS 499 Computer Science Capstone.

The application uses Python, MongoDB, Dash, and Plotly to retrieve, filter, and visualize animal shelter records.

## Key Enhancements

- MongoDB database indexing and query performance analysis
- Improved database search validation and pagination
- Environment-variable-based database credential configuration
- Enhanced Water, Mountain, and Disaster Rescue filters
- Interactive animal data table and breed distribution chart
- Interactive map with animal information popup
- Database functionality and performance testing

## Technologies Used

Python | MongoDB | PyMongo | Dash | Plotly | Pandas | Jupyter Notebook
